# G-1-2 Matmul カーネル

M=4, K=4, N=4、TILE=2 の例で説明。

全体の目標
行列 C = A × B を計算する。
```
A (4×4)    B (4×4)    C (4×4)
[a00 a01]  [b00 b01]  [c00 c01]
[a10 a11]  [b10 b11]  [c10 c11]
...        ...        ...
```

C の各要素は C[row][col] = Σ A[row][k] * B[k][col]。

---

スレッドの割り当て
```
@workgroup_size(TILE, TILE, 1) = (2, 2, 1) → 4スレッド/ワークグループ
```

各スレッドが C の 1要素 を担当

```
スレッド(lid.x=0, lid.y=0) → C[0][0] を計算
スレッド(lid.x=0, lid.y=1) → C[0][1] を計算
スレッド(lid.x=1, lid.y=0) → C[1][0] を計算
スレッド(lid.x=1, lid.y=1) → C[1][1] を計算
```

---
ループの流れ（TILE=2、K=4 → 2タイル）
タイル t=0：K の 0〜1 列目を共有メモリにロード

```
tileA = A の左半分    tileB = B の上半分
[a00 a01]             [b00 b01]
[a10 a11]             [b10 b11]
```

workgroupBarrier() — 全スレッドのロード完了を待つ

```
acc += tileA[lid.x][0]*tileB[0][lid.y] + tileA[lid.x][1]*tileB[1][lid.y]
```

スレッド(0,0) の場合：`acc += a00*b00 + a01*b10`

workgroupBarrier() — 次のタイルロードの前に積算完了を待つ

タイル t=1：K の 2〜3 列目をロード

```
tileA = A の右半分    tileB = B の下半分
[a02 a03]             [b20 b21]
[a12 a13]             [b30 b31]
```

barrier → 積算

スレッド(0,0) の場合：`acc += a02*b20 + a03*b30`

最終的に スレッド(0,0) の `acc = a00*b00 + a01*b10 + a02*b20 + a03*b30 = C[0][0]`

```
[全スレッド] tileA・tileB にロード
    ↓
workgroupBarrier() ← ① 全員がロードし終わるまで待つ
    ↓
[全スレッド] tileA・tileB を読んで acc に積算
    ↓
workgroupBarrier() ← ② 全員が積算し終わるまで待つ（次のタイルを上書きする前に）
    ↓
[全スレッド] 次のタイルをロード（tileA・tileB を上書き）
```

① がないと：あるスレッドがまだロード中なのに別のスレッドが古いデータを読む
② がないと：あるスレッドが次のタイルを書き始めて、別のスレッドの積算データが壊れる

---
lid vs gid の使い分け

```
gid（global）= ワークグループ全体での絶対座標 → 出力 C のどの行・列か
lid（local）  = ワークグループ内の相対座標   → タイル内のどの位置か
```

```
row = gid.x  → C の何行目を担当するか
col = gid.y  → C の何列目を担当するか
lid.x, lid.y → タイル内のロード位置
```
