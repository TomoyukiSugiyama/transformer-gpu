## [C] Cross Entropy loss（GPU）

* CPU側は softmax を明示的に計算してから log を取る
* GPU側は probs を全部保存できないため、`max_val` と `sum_exp` のスカラー2個だけ持てば良い `log-sum-exp` で Cross Entropy Loss を算出

CPU側をGPU側の計算方法に合わせても良い。

```
CPU版: logits → probs (保存) → loss, probs → grad
1. Softmax
2. Loss
3. dlogits[i,j] = probs[i] - 1(i == target)

GPU版: logits → lse (スカラー) → loss と grad を同一ループで計算
1. max_val = max_j logits[i,j]
2. sum_exp = Σ_j exp(logits[i,j] - max_val)
3. lse = max_val + log(sum_exp)
4. loss_i = lse - logits[i, target_i]
5. dlogits[i,j] = exp(logits[i,j] - lse) - 1{j=target_i}
```
