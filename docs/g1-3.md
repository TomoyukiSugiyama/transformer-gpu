## [A] カーネルの追加

Flash Atention の位置付け

```
Fused Attention（広義）
└── 複数カーネルを1つに融合するアプローチ全般
    ├── 単純なFusion: QK^T + softmax + V を1カーネルで
    └── Flash Attention: Fusionに加えてIO最適化まで行う
```

単純な Fused Attention との違い

|           | 単純 Fused Attention | Flash Attention        |
| --------- | ------------------ | ---------------------- |
| カーネル数     | 1つに統合              | 1つに統合                  |
| scores行列  | HBM（VRAM）に書き出す     | HBMに書かない               |
| メモリ使用量    | O(seq²)            | O(seq)（線形）             |
| softmax方式 | 2パス（max→sum別々）     | Online softmax（1パスで更新） |
| タイリング     | オプション              | 必須（SRAM内で完結）           |
| 実装難度      | 中                  | 高                      |

`attention.wgsl` の qkt / softmax_causal / attn_v カーネルを廃止し、
`flash_attention.wgsl` に flash_attention カーネル (`workgroup_size(Br=64, 1, 1)`) を追加、

flash_attention カーネルでは、事前に workgroup memory (`tile_q` / `tile_k` / `tile_v`) にロードしておき、HBM (外部メモリ側のバッファ) へのアクセス を減らす。

```
var<workgroup> tile_q: array<f32, Br * MAX_D_HEAD>; // [Br][d_head]
var<workgroup> tile_k: array<f32, Bc * MAX_D_HEAD>; // [Bc][d_head]
var<workgroup> tile_v: array<f32, Bc * MAX_D_HEAD>; // [Bc][d_head]
```

実行前に tile にロードする。

```wgsl
// tile_q にロード
for (var d: u32 = 0u; d < d_head; d++) {
    tile_q[lid.x * d_head + d] = fa_q[row * d_head + d];
}
```

d_head の最大値は固定値として設定しているため、128 を超えると溢れる。

`const MAX_D_HEAD: u32 = 128u;`

---

`attention.rs` でパイプラインを実行

```rust
pass.set_pipeline(&fa_pipeline);
pass.set_bind_group(0, &fa_bind_group, &[]);
pass.dispatch_workgroups(seq.div_ceil(BR), 1, 1);
```
