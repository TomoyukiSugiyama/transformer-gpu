## [B] RMSNorm カーネルの追加

入力する x はフラットにマッピングされているので、各行に対して RMSNorm を計算する。

```
x の全体レイアウト（seq=4, d_model=1024）:

インデックス:  0        1023 1024     2047 2048     3071 3072     4095
              [---行0---]   [---行1---]   [---行2---]   [---行3---]

base=0    → x[0..1023]    ← 行0
base=1024 → x[1024..2047] ← 行1
base=2048 → x[2048..3071] ← 行2
base=3072 → x[3072..4095] ← 行3
```

ワーキンググループサイズ=256, d_model=1024 の場合、256 の各スレッドは 4 つ (1024/256 = 4) を担当する。

```
const WG: u32 = 256u;
@workgroup_size(WG, 1, 1)
```

各スレッドで、x の冪乗を 4 つ分加算。

```
tile[0] = x[0]*x[0] + x[256]*x[256] + x[512]*x[512] + x[768]*x[768]

tile[0] ~ tile[WG-1] 各タイルに4個分の和が含まれる
```

tree reduction で workgroup 内の sum を計算。

```
stride = 128: tile[0]+=tile[128],tile[1]+=tile[129], ... ,tile[127]+=tile[255]
stride = 64: tile[0]+=tile[64],tile[1]+=tile[65], ... ,tile[63]+=tile[127]
...
stride = 1: tile[0]+=tile[1]
```

tile[0] に sum の結果が入るので、rms を計算。
rms から rms norm を計算。

## [C] RoPE カーネルの追加
CPU 側で cos テーブル、sin テーブルを用意し、
GPU 側にテーブルを渡して計算

```
let x0 = x[base_x + 2u * i];
let x1 = x[base_x + 2u * i + 1];
let c = cos_table[base_tbl + i];
let s = sin_table[base_tbl + i];

out[base_x + 2u * i]     = c * x0 - s * x1;
out[base_x + 2u * i + 1] = s * x0 + c * x1;
```
