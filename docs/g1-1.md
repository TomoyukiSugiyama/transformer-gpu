## [A] wgpu/bytemuck/pollster を導入し、GPUへ接続確認

shader で arguments を2倍にして出力するシェーダーを用意

```wgsl
@group(0) @binding(0)
var<storage, read> input: array<f32>;

@group(0) @binding(1)
var<storage, read_write> output: array<f32>;

@compute @workgroup_size(64)
fn doubleMe(@builtin(global_invocation_id) global_id: vec3<u32>) {
    let index = global_id.x;

    let array_length = arrayLength(&input);
    if(index >= array_length) {
        return;
    }

    output[index] = input[index] * 2.0;
}
```

Metal (Apple Silicon) で、以下を確認する。
- GPU システム内の物理 GPUを表す `Adapter` の情報を確認
- `[0.1, 0.02, 1.0]` を入力して、`[0.2, 0.04, 2.0]`が返ってくる

動作確認結果:

```
Running on Adapter: Adapter {
    inner: Core(
        CoreAdapter {
            context: ContextWgpuCore {
                type: "Native",
            },
            id: Id(0,1),
        },
    ),
}
Result: [0.2, 0.04, 2.0]
```

## [B] テスト基盤の準備

`src/test_utils.rs` に random_f32、assert_close を追加

- `random_f32(len: usize, seed: u64)` 
- `assert_close(gpu: &[f32], cpu: &[f32], rel_eps: f32, abs_eps: f32)`  gpu と cpu の計算結果を比較するツールであるが、
  出力結果に誤差が生じるため、rel_eps (相対誤差)、abs_eps (絶対誤差)を設定する。

| カーネル                  | rel_eps | abs_eps |
| --------------------- | ------- | ------- |
| Softmax（出力 [0,1]）     | 1e-5    | 1e-7    |
| RMSNorm（出力 [-1,1] 程度） | 1e-5    | 1e-6    |
| Matmul（出力が大きい）        | 1e-5    | 1e-6    |
| Attention（累積誤差あり）     | 1e-4    | 1e-6    |

## [C] ワークグループサイズの方針を決める

Metal (Apple Silicon) で最大のワークグループサイズを確認

```
max_workgroup_size x=1024 y=1024 z=1024
max_workgroup_invocations=1024
```

タイル を 16×16 (256スレッド) で実装し、動作確認後に 32X32 (1024スレッド) へ変更しパフォーマンスの検証を行う。

| バックエンド                | max_workgroup_size (x,y,z) | 推奨タイル          |
| --------------------- | -------------------------- | -------------- |
| Metal (Apple Silicon) | 1024 total                 | 16×16 or 32×32 |
| Vulkan                | 通常 1024〜2048               | 16×16 or 32×32 |
| DX12                  | 1024                       | 16×16          |
| WebGPU (ブラウザ)         | 256 total                  | 16×16          |
